## Flag: Config / Playbook min_rel_volume Discrepancy

`state/config.json` has `min_rel_volume: 1.2`. The playbook (docs/PLAYBOOK.md) and CLAUDE.md
specify 1.5x for ORB setups. These are different numbers.

At 09:40 AM today, INTC had rel_vol of 1.22x. Under the config figure (1.2), this would pass.
Under the playbook figure (1.5), it fails. The intraday agent applied 1.5x, which is correct.
However, having two different numbers in two authoritative sources is a latent bug — a future
tick could pick up the wrong value and enter a trade on 1.22x volume when the intent is to
require 1.5x.

This must be resolved before the next session. The recommended fix is to update `config.json`
to `min_rel_volume: 1.5` to match the playbook. If the tuner previously set 1.2 as part of
an auto-tune step, that step should be reviewed. The playbook value of 1.5x is the
authoritative floor.
