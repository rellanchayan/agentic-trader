## Lessons for Tomorrow

1. A position carried overnight means the end-of-day flatten failed or was never run. Before any
   tick logic runs, check `--positions` and if anything is open, close it immediately with a fresh
   market-adjacent limit — do not use any cached price from a prior session.

2. A sell limit set below the current bid is a no-op, not a safety net. Before submitting any limit
   order, confirm the limit is within a reasonable spread of the last trade price. A $20 miss on a
   $370 stock is a 5.4% error that a five-second quote check would have caught.

3. The premarket run is not optional. Without it, there is no loss-stop baseline, no watchlist, and
   no orientation. A day that opens with a surprise position and no plan is a day where the only
   correct action is to flatten and sit out. Today that is exactly what happened — but it should be
   a rule, not an accident.
